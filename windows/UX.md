# Windows 桌面交互

以 PR #7 的 [macOS 交互基线](../docs/macos-ux-reference-for-windows.md) 和十张已有预览图为参考，保留 C# / WPF / Win32 架构，不引入 Electron、HTML 主界面或新的 UI 运行时。

## 屏幕边缘与余额速览

- 平时是 6 DIP 宽的品牌色把手；靠近时轻微展开并短暂发光。
- 距离入口约 88 DIP 内停留 200 ms，出现 260 DIP 宽的余额卡片。不激活窗口、不抢输入焦点，也不展开完整组件。
- 鼠标进入速览卡片时保留；离开 130 DIP 范围超过 300 ms 后淡出。进入/离开采用不同阈值，避免边缘来回闪烁。
- 不创建覆盖大面积桌面的透明捕获窗口；只读查询鼠标位置，不安装全局鼠标钩子。全屏外部应用前不弹出，桌面本身不算全屏应用。
- 账户模式显示账户余额；共享 Key 只显示服务端提供的近似百分比，不推算精确账户余额。未知额度显示「暂不可用」，不伪造 100%。
- 隐私设置可让速览只显示百分比。超过五分钟未同步会标注旧数据。
- 点击卡片打开完整小组件；单纯靠近不会打开管理中心。

## 原生拖动与动效

管理中心和小组件的非交互内容均可拖动，包括普通文字、额度卡片和空白区域。超过 Windows 拖动阈值后使用原生移动循环；按钮、链接、输入框、下拉选择和滚动条不会触发拖动。小组件释放后用约 180 ms 的缓出贴边，落定后保存位置，而不是每个鼠标事件写文件。

面板进入使用约 170 ms 淡入和 230 ms 的小幅位移；退出约 120 ms。协议/模型展开使用约 210 ms 高度过渡，侧栏约 190 ms。重开会取消上次关闭，避免快速操作把已重新打开的窗口隐藏。

关闭应用动效或 Windows 客户区动画时立即切换。微光只有靠近和刷新完成时短暂出现，不做常驻循环。

## 信息层级

- 小组件：身份 → 余额 → 当前 Key / 接入信息 → 协议 / 模型 → 已安装客户端 → 全部配置管理 / 登出。
- 协议与模型详情互斥展开，模型可搜索、选择和独立复制 ID。复制后就地显示短暂反馈。
- 管理中心：账户概览、API Keys、客户端适配、模型目录、连接测试、设置。
- 管理中心每次启动默认展开 208 DIP 侧栏，仍可手动收为 76 DIP 图标栏。暖灰/深灰侧栏和独立窗口边界便于区分邻接应用，底部保留账户入口和品牌。
- 账户概览与小组件共用连接面板：切换/复制/新增 Key、复制完整接入信息、五种协议地址、模型搜索/选择/复制 ID。另有全部已安装客户端、刷新、检查连接、固定面板、偏好设置、Key 管理、兑换和登出。未登录时可以直接从概览选择账户或 API Key 登录。
- 概览客户端卡片在窄窗口自动改单列，避免大量名称被截断。客户端适配列表统一图标列、双行文字和 48 DIP 行高。顶部状态与窗口控制对齐，不随同步状态插入进度条挤动正文。
- 只显示检测到的客户端。数量不超过 4 时全显示，超过 4 时显示最近 3 个及「更多」。管理中心也应用安装筛选和最近排序。
- API Key 登录提供等高的显式粘贴按钮；从小组件新增 Key 会打开管理中心 API Keys 页面，建议第一个可用的 YConnect-N，自动聚焦并选中名称。

## 外观与透明

主操作色 #B45D4B，品牌强调色 #C76A55。暖白/炭灰底色，原生矢量标识、统一圆角输入框、下拉菜单和复选框。

完整组件宽 400 DIP、外壳圆角 20 DIP。默认演示内容高度约 660 DIP，卡片内边距 10–16 DIP，区块间距以 8–14 DIP 为主。连接行和模型名使用 12 DIP 字号，统一图标位置与垂直居中。普通按钮约 32 DIP 高、输入框至少 34 DIP 高，API Key 登录输入与粘贴仍保持一致的 40 DIP。

管理中心默认 1080 × 760 DIP；概览额度卡与统计卡等高，Key 使用紧凑行，配置页将 Key 与模型并排。鼠标选择采用柔和底色，键盘导航保留独立焦点装饰，不参与布局；协议标题保留 8 DIP 内缩，避免描边贴住文字。按钮文案保持单行，复制反馈预留固定宽度，不因「已复制」换行改变高度。

正文使用不透明背景，仅圆角外缘和阴影透明。高度按实际工作区限制；放不下时滚动，不裁掉内容。最小管理窗口仍保留侧栏底部账号。

## 验证边界

自动化只在隔离演示进程中操作自身窗口。原生屏幕合成截图用于检查透明/阴影；高 DPI RenderTargetBitmap 与定位几何测试用于检查 100% / 125% / 150% 的排版和边界，不冒充跨真实显示器测试。

安全边界与原有适配器保留：公开账户 Cookie / 业务 Bearer 分离、DPAPI 会话和备份、私有 ACL 凭证文件、预览后确认、多文件回滚、外部更改检测、付费调用二次确认、登出不删除客户端配置。实际结果及未完成的在线授权范围见 [验证记录](VALIDATION.md)。
