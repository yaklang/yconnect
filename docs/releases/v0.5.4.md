# Y CONNECT 0.5.4

macOS 现在可以选择启动 Agent 的默认终端。在“客户端适配”中选择 Agent，在“启动 Agent”区域的启动按钮下方选择“默认终端”。正式保障 macOS Terminal、iTerm2 和 Ghostty；kitty、WezTerm、Alacritty 为可选兼容入口，不保证所有环境可用。只允许选择已安装的终端，并记住选择。已选终端被移除时，自动回退到 macOS Terminal 并显示提示。

- “在终端启动 Agent”和“仅打开专用终端”使用相同的默认终端设置，每次启动仍使用独立模型、工作目录和会话凭据。
- iTerm2 使用原生会话文件打开方式，不需要额外的 AppleScript 自动化授权；如 iTerm2 询问是否运行会话文件，请确认。等待超时会安全取消未使用的请求，处理提示后可重试。
- 新安装的终端请先按 macOS 的提示打开一次，再从 Y CONNECT 启动会话。
- WezTerm 为新会话启动独立进程，不把启动请求转交给已经运行的实例。
- 启动失败时取消未使用的会话并删除其临时密钥；不影响已经启动的会话。终端启动使用系统 zsh 的绝对路径。
- 保留 0.5.3 的 macOS Tahoe 启动、菜单栏窗口编号及关闭/最小化后重新打开修复。
- Windows 功能保持与 0.5.3 一致，提供经过签名和升级验证的同步版本。

macOS 14+（Apple Silicon / Intel）；Windows 10/11 x64。0.5.0 及以上版本可在客户端“检查更新”，更旧版本请下载新安装包。
