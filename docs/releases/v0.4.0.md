# Y CONNECT 0.4.0

本次更新改善 macOS 启动与钥匙串异常处理，并为两端小组件和管理中心增加兑换码入口。

- **打开就能看到界面**：手动启动主动显示小组件，再次点击应用会唤回窗口；登录项自动启动保持后台运行。菜单栏暂时不可用时，小组件会在可见屏幕内显示。
- **钥匙串异常有提示**：凭据操作移到独立队列，避免阻塞界面；修正 macOS 钥匙串属性兼容性。授权被拒绝、钥匙串锁定或暂时不可用时显示原因与错误码，保留原凭据，不降级为明文存储。
- **启动兜底与诊断**：客户端适配初始化失败时仍可打开账户和小组件；上次异常退出后提供提示与诊断文件夹入口。诊断不记录 Key、Cookie 或会话内容。
- **兑换更方便**：macOS 和 Windows 的管理中心、小组件新增兑换码入口；校验输入、阻止重复提交，并区分处理中、失败和到账成功。到账后余额同步失败时提示刷新，避免误报兑换失败。

这些改动针对已发现的启动与凭据访问风险；由于缺少反馈设备的崩溃报告，尚不能确认其闪退根因。
