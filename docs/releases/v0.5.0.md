# Y CONNECT 0.5.0

新版本，点一下就能开始更新。

- 小组件、管理中心和菜单新增更新入口；设置中可手动检查更新、查看更新说明和关闭自动检查。
- 启动后及每六小时安静检查一次，有新版本时显示提示，不会自动安装或强制中断工作。
- macOS 通过 Sparkle 下载、验证签名、替换应用并重新打开；需要权限时使用系统授权。
- Windows 通过 WinSparkle 下载并验证更新，安装时显示进度，成功后重新打开。便携版会先询问是否转为安装版，原目录保留。
- 账户、API Key 与客户端配置保留；下载中断、无网络或校验失败时继续使用当前版本，可重试或手动下载。
- 发行流程自动生成两端更新订阅源，对最终安装包进行 Ed25519 签名；只有两端构建、签名与校验完成后才更新公开版本索引。

0.4.0 及更早版本需要先手动安装本版本一次，后续可在客户端内更新。
