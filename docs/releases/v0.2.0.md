# YConnect 0.2.0

原生桌面连接与模型客户端适配中心：macOS 使用 Swift/AppKit，Windows 使用 C#/WPF，不使用 Electron。

## 下载与安装

- **Windows 10/11 x64**：`YConnect-0.2.0-windows-x64-setup.exe` 为当前用户安装；`YConnect-0.2.0-windows-x64.zip` 为免安装便携版。需要 .NET Framework 4.8 或更新版本；扫码登录按需使用系统 WebView2。
- **macOS 14+**：`YConnect-0.2.0-darwin-universal.dmg` 同时支持 Apple Silicon 和 Intel，打开后将 YConnect 拖入 Applications。
- `SHA256SUMS.txt` 包含上述三个附件的 SHA-256 校验值。

## 本次改进

- Windows 屏幕边缘余额速览、轻微发光与开合动画、原生拖动和贴边。
- 管理中心默认展开暖灰侧栏，底部保留品牌和账户；客户端列表对齐，窄窗口自适应。
- 账户概览集中提供 Key、模型、协议复制、客户端适配与常用操作。
- 小组件焦点与选中态不挤动布局，复制反馈不会换行改变高度。
- 8 个原生客户端适配器，配置预览、加密备份、外部变更检测和恢复。

## 验证与发行说明

Release 仅在 Windows 与 macOS CI 全部成功后发布。Windows 执行核心和 WPF 布局测试，以及安装/卸载校验；macOS 执行 Swift 测试、UI 渲染与焦点检查，并校验通用 DMG 内的两种架构。
