# Y CONNECT 0.5.1

- 修复 macOS 客户端适配页 Agent 卡片只有文字附近可点击的问题，图标、边缘留白和整张卡片均可选择客户端。
- Agent 卡片统一高度，图标、名称和协议说明对齐；长协议说明最多显示两行，悬停可查看完整内容，选中状态不再改变布局。
- 增加 macOS 卡片边缘点击与等高回归，以及 Windows 客户端选择行在深浅主题、宽窄窗口下的整行命中和尺寸检查。
