# Y CONNECT 0.5.3

- 修复新版 macOS 托盘窗口编号超出 Quartz 32 位范围时的启动崩溃；无法查询 Quartz 坐标时使用 AppKit 坐标回退。
- 修复管理窗口关闭后从 Finder 重新打开、最小化后从菜单或 Finder 恢复的问题。
- 登录项、系统服务及显式后台启动保持安静；手动启动继续显示小组件。
- 切换页面取消模型列表请求时不再误报网络错误，保留已有模型列表；真实网络故障仍正常提示。
- 增加 macOS 26 Apple Silicon / Intel 编译测试，以及实际通用安装包的启动、Finder 重开、最小化恢复和托盘交互回归。发布前验证签名安装包。
