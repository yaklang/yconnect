# Y CONNECT 0.3.0

本次更新完善账户充值、独立 Agent 启动与消费速览，并首次提供经过正式签名的跨平台发行包。

- macOS：原生扫码充值、消费速览、独立终端 Agent 会话，以及 Grok Build 上下文设置。
- Windows：独立启动器、原生充值、模型诊断，修复终端路径和交互兼容性。
- 两端统一 Y CONNECT 品牌、版本显示与请求头版本。
- macOS Universal 应用经过 Developer ID 签名及 Apple 公证，应用和 DMG 均附加公证票据。
- Windows 主程序、启动器、凭据助手和安装/卸载程序均经过 Authenticode 签名及时间戳验证。
- 同步发布 GitHub Releases 与 YConnect OSS 目录，提供完整 SHA-256、版本 manifest、历史索引及 version.txt。
