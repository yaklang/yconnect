# Y CONNECT 0.5.2

- macOS 与 Windows 账户充值页新增「优惠信息同 YAKCOOL 官网」提示，可点击直达官网充值优惠区。
- 明确说明「充值赠金政策同步官网，具体细则以官网通知为准」，方便充值前查看当前优惠。
- 客户端不固定展示赠金比例，优惠政策以官网最新通知为准。
